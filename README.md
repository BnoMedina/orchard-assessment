# Orchard FED Skill Assessment

## 📋 Overview
This project implements the Orchard FED skill assessment design faithfully using **HTML, CSS, and vanilla JavaScript**. A production-ready build process was added with **Webpack**, and the project is deployed on **GitHub Pages**.

🔗 **Live Demo:** [https://bnomedina.github.io/orchard-assessment/](https://bnomedina.github.io/orchard-assessment/)  
🔗 **Repo:** https://github.com/bnomedina/orchard-assessment

---

## 🚀 Features
- Pixel-accurate layout from the Zeplin design
- Responsive design (desktop → mobile down to 320px)
- Accessible modal with focus trap & ESC close
- Cards block with semantic links, console-logged clicks
- SEO meta tags + descriptive alt text
- Production build with Webpack (bundled JS, extracted CSS, copied assets)

---

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript (no SPA frameworks, no Tailwind)
- Build: Webpack 5
- Hosting: GitHub Pages

---

## 🔧 Setup
Clone repo:


git clone https://github.com/bnomedina/orchard-assessment.git
cd orchard-assessment
npm install
npm start

Build for production:
npm run build

The build outputs to /dist.
